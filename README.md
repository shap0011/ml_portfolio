# Machine Learning Portfolio (Jekyll)

A static portfolio website built with **Jekyll** to present machine learning and data analysis work
developed using **Python**. The site is deployed with **GitHub Pages**.

## 🌐 Live Website

https://shap0011.github.io/ml_portfolio/index.html

## 📌 Portfolio Content

The portfolio highlights:

- Data exploration and preprocessing
- Data cleaning techniques
- Machine learning concepts and workflows
- Python-based analysis using Jupyter notebooks
- Structured presentation of ML coursework examples

## 🛠 Tech Stack

- **Languages:** Python
- **Machine Learning / Data:** pandas, NumPy, scikit-learn
- **Static Site Generator:** Jekyll
- **Deployment:** GitHub Pages
- **Tools:** Jupyter Notebook, VS Code, Git, GitHub

## 📂 Related Repository (Code Examples)

All machine learning examples and notebooks showcased on this site are located in:

👉 https://github.com/shap0011/machine_learning_fall_2024

This repository contains:

- Jupyter notebooks
- Data preprocessing examples
- Machine learning experiments completed during coursework

## 🎯 Project Purpose

This project demonstrates:

- Organizing and presenting machine learning work in a professional portfolio
- Using Jekyll to build static documentation-style websites
- Applying Python-based data analysis and ML techniques
- Publishing technical content using GitHub Pages

## ▶️ Run Locally

```bash
git clone https://github.com/shap0011/ml_portfolio.git
cd ml_portfolio
bundle install
bundle exec jekyll serve
```
